# Jogo de Adivinhação

Projeto em Java para praticar lógica de programação por meio de um jogo de adivinhação executado no console.

## Objetivo

O jogo permitirá escolher entre diferentes níveis de dificuldade, tentar descobrir um número gerado pelo computador e consultar o histórico das últimas pontuações.

## Requisitos principais

- Menu principal com opções para iniciar uma partida, ver as regras, consultar o histórico e sair.
- Três níveis de dificuldade.
- Pontuação dinâmica.
- Histórico das 10 últimas pontuações.
- Uso explícito de arrays, loops e estruturas de seleção.
