# Click Counter Design

## Goal

Build an independent React and TypeScript application for task 01 that displays a button and the number of times the user has clicked it.

## Application Structure

`tarefa-01/` will contain a Vite application using React and TypeScript. The app will have one root component, `App`, responsible for rendering the title, the current count, and the increment button.

## Interaction

The counter starts at `0`. Clicking the button increments the value by exactly one through React's `useState` hook. The displayed value updates immediately after every click.

## Documentation

`tarefa-01/README.md` will document the commands to install dependencies, run the development server, and execute the test suite.

## Testing

A component test will verify the initial count and confirm that a button click updates the visible count from `0` to `1`.

## Constraints

- Use React and TypeScript.
- Keep task 01 independent from the other task directories.
- Use English Conventional Commit messages.
